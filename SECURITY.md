# Security Policy

## Supported Versions

The latest released version of this repository is the only supported version.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue.
2. Open a **Discussion** post under the category "Security" on this repository, or
3. Contact the maintainers via GitHub's contact form.

We will acknowledge receipt of your report within 72 hours and aim to provide a fix or mitigation within a reasonable timeframe based on severity.

## Scope

This policy covers the repository's source code, workflows, and documentation. It does not cover vulnerabilities in third-party services linked from these pages.

## Disclosure

Please provide as much detail as possible:

- A description of the vulnerability and its impact
- Steps to reproduce
- Affected versions
- Any proof of concept or suggested fix
